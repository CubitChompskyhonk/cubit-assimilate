CUBIT ASSIMILATE · v0.2 · VAULT LIVE

Founder device assimilation

Scoped backup to Google Drive · biometric gate · no silent control

1 · What this is

  • Backs up what you enable to Head Offices → Device Vault
  • Uses Android permission dialogs — nothing hidden
  • Does not read SMS, call logs, or messengers in v1
  • Does not claim root or secret device admin

2 · Scopes

Core — network, notifications, biometric (required)
Photos & videos — Tier B (MediaStore / picker)
Folders I select — Tier C (SAF)
Broad all-files — Tier D (advanced, not default)

Native Android permission prompts appear only in the signed APK build — this web shell records intent.

3 · Founder key

High-risk actions (first backup, Tier D, vault wipe) require device biometrics or screen lock. Native BiometricPrompt ships in the APK.
