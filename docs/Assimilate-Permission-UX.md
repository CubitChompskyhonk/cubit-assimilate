# Assimilate — Permission UX Copy (v1)

## Screen 1 — What this app is
**Cubit Assimilate**  
Backs up **what you choose** to your Google Drive vault and runs the Cubit company layer on this phone.

It will **not** read SMS, call logs, or personal messengers in this version.  
It will **not** hide itself or run a secret admin profile.
